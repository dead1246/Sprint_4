# Sprint_4

## Тесты для класса BooksCollector

В проекте реализованы автотесты для проверки работы класса `BooksCollector`.

### Реализованные тесты

1. Проверка добавления новой книги в словарь.
2. Проверка, что у новой книги жанр по умолчанию пустой.
3. Проверка, что книгу нельзя добавить повторно.
4. Проверка, что нельзя добавить книгу с пустым названием.
5. Проверка, что нельзя добавить книгу с названием длиннее 40 символов.
6. Проверка установки жанра книге.
7. Проверка получения жанра книги по названию.
8. Проверка получения списка книг с определённым жанром.
9. Проверка получения словаря books_genre.
10. Проверка получения списка книг, подходящих детям.
11. Проверка добавления книги в избранное.
12. Проверка, что книга не добавляется в избранное повторно.
13. Проверка удаления книги из избранного.
14. Проверка получения списка избранных книг.

### Запуск тестов

```bash
pytest -v tests.py
